Datenschutz

Allgemeines

Diese Website stellt die webbasierte SQL-Lernumgebung „Schulazon“ bereit. Die Anwendung läuft clientseitig im Browser. Es werden durch mich keine personenbezogenen Daten auf einem eigenen Server gespeichert.

Hosting über GitHub Pages

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website können durch GitHub technisch notwendige Zugriffsdaten verarbeitet werden, insbesondere IP-Adresse, Zeitpunkt des Abrufs, aufgerufene Dateien, Browserinformationen und Geräteinformationen. Diese Verarbeitung erfolgt durch GitHub zur Bereitstellung, Sicherheit und Stabilität des Hosting-Dienstes.

Lokale Speicherung im Browser

Die Anwendung kann Spielstände, Fortschritte, Aufgabenbearbeitungen, eingegebene SQL-Abfragen, Punktestand, Sitzungsinformationen und Einstellungen lokal im Browser speichern, insbesondere über localStorage und sessionStorage. Diese Daten bleiben grundsätzlich auf dem verwendeten Endgerät und werden nicht automatisch an mich übertragen.

Export von Daten

Soweit die Anwendung eine Exportfunktion bereitstellt, erfolgt ein Export nur durch eine bewusste Aktion der nutzenden Person. Erst dadurch können lokal gespeicherte Daten als Datei ausgegeben und außerhalb des Browsers weitergegeben werden.

Cookies, Tracking und Analyse

Diese Website verwendet keine eigenen Tracking-Cookies, keine Webanalyse-Dienste, keine Werbung und keine eigenen Nutzerkonten. Eine Profilbildung zu Werbezwecken findet nicht statt.

Externe Ressourcen

Die Website kann externe Ressourcen einbinden, insbesondere Schriftarten und JavaScript-Bibliotheken. Beim Abruf solcher Ressourcen können die jeweiligen Anbieter technisch notwendige Zugriffsdaten verarbeiten.

Kontakt und Löschung lokaler Daten

Datenschutzbezogene Anfragen können an die oben genannte E-Mail-Adresse gerichtet werden. Lokal gespeicherte Daten können durch Löschen der Website-Daten im Browser entfernt werden.
