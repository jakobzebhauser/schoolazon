Schulazon – SQL Tutorial

1. SELECT – Grundidee

Mit SELECT sagst du der Datenbank, welche Daten du sehen willst.
Mit FROM sagst du, aus welcher Tabelle die Daten kommen.

* bedeutet: alle Spalten anzeigen.
Aufgabe: Zeige alle Produkte an.
SELECT * FROM produkte;

2. WHERE – Filtern

Mit WHERE filterst du Zeilen.

Beispiel: preis < 25 bedeutet „billiger als 25 €“.
Du kannst vergleichen mit = < > <= >=.
Aufgabe: Zeige alle Produkte, die weniger als 25 € kosten.
SELECT * FROM produkte WHERE preis < 25;

3. ORDER BY – Sortieren

Mit ORDER BY sortierst du Ergebnisse.

ASC = aufsteigend
DESC = absteigend
Aufgabe: Sortiere alle Produkte nach Preis (teuer → billig).
SELECT * FROM produkte ORDER BY preis DESC;

4. GROUP BY & HAVING

GROUP BY fasst mehrere Zeilen zusammen.
SUM() zählt Werte zusammen.

HAVING filtert nach dem Rechnen (nicht wie WHERE).
Aufgabe: Zeige alle Produkte, die mehr als 300-mal verkauft wurden.
SELECT produkt_id, SUM(anzahl) FROM verkäufe GROUP BY produkt_id HAVING SUM(anzahl) > 300;
