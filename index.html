Wie läuft das?

          

            Du löst 4 kurze SQL-Aufgaben auf der Schulazon-Datenbank. Daraus wird eine Modus-Empfehlung abgeleitet:
            
    
              
  • 0–2 korrekt → Guided Mode (strukturierter Aufbau)
    • 
              
  • 3–4 korrekt → Free Mode (mehr Freiheit)
    • 
            

            Du kannst jederzeit über die Buttons oben direkt in einen Modus springen.
          


          

            

              
TIPPS

              
Output-Formate

            

            
1) Gib meist Produkt-IDs aus: SELECT id FROM produkte;

2) Nur SELECT: keine INSERT/UPDATE/DELETE/...
3) Bei Sortierung: ORDER BY ... (stabil mit id als Tie-Breaker)
4) Wenn verlangt: 1 Zahl (scalar) in 1. Spalte
